# SamosGames — браузерные игры

Коллекция браузерных игр и экспериментов SamosGames Team.

## Игры

В коллекции есть раннеры, tower defense, шутер, лабиринт, головоломка и idle/RPG. Каждая игра находится в отдельной папке и запускается как самостоятельная статическая страница.

## Запуск

```bash
npm run dev
```

Или: `python3 -m http.server 8000`.

Откройте http://localhost:8000.

## Структура

- `index.html` — каталог игр;
- `games/` — отдельные игры;
- `docs/` — документация.
